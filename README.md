## 📌 About

This repository contains a collection of Machine Learning mini projects created to understand the fundamentals of Data Science and AI.

The projects cover:

- 📊 Data Analysis
- 📈 Data Visualization
- 🤖 Machine Learning Algorithms
- 📉 Model Evaluation
- 🔍 Prediction & Classification

These projects are perfect for beginners who want hands-on experience with Machine Learning.

---

# 📂 Projects Included

## 🎯 Project 1 — Student Performance Predictor

### 📖 Description

Predict students' exam scores based on the number of hours they studied using **Linear Regression**.

### Topics Covered

- Data Loading
- Data Exploration
- Data Visualization
- Train/Test Split
- Linear Regression
- Mean Absolute Error
- Predictions

### Technologies

- Python
- Pandas
- Matplotlib
- Scikit-Learn

---

## 🌸 Project 2 — Iris Flower Classifier

### 📖 Description

Classify Iris flowers into different species using the **k-Nearest Neighbors (k-NN)** algorithm.

### Topics Covered

- Iris Dataset
- Train/Test Split
- k-NN Classifier
- Feature Scaling
- Accuracy Evaluation
- Classification Report
- Confusion Matrix

### Technologies

- Python
- Scikit-Learn
- Pandas

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/pranita35/AI-ML-Projects.git
```

Move into the project folder

```bash
cd AI-ML-Projects
```

Install dependencies

```bash
pip install pandas matplotlib scikit-learn
```

Run the notebook or Python file.
